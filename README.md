# Application of Machine Learning Methods for Feed Chemical Properties Analysis

This repository contains the code and data used in the coursework on the application of machine learning methods for analyzing the chemical properties of feeds.

## Project goal
The goal of this project is to study the use of machine learning methods for analyzing the chemical properties of feeds.

## Files
- `main.py` — main project code
- `cluster_profile.csv` — cluster profile data
- `clustering_metrics_all.csv` — clustering metrics
- `silage_with_clusters.csv` — dataset with cluster labels

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
